# 🩸 LifeBlood - Blood Bank Management System

LifeBlood is a web-based **Blood Bank Management System** designed to manage blood donors, hospitals, blood requests, blood inventory, and donation schedules.

The system provides separate access for:

* 👤 Donors
* 🏥 Hospitals
* 🛡️ Administrators

---

## 📌 Project Overview

Blood is an essential resource that can save lives during emergencies, surgeries, accidents, and medical treatments.

The **LifeBlood Blood Bank Management System** helps organize the blood donation and blood request process through a simple and user-friendly web interface.

The system allows administrators to manage donors, hospitals, blood inventory, blood requests, and donation schedules.

---

## 🎯 Objectives

* To maintain donor information.
* To manage blood group information.
* To manage blood inventory.
* To allow hospitals to request blood.
* To maintain donor donation schedules.
* To provide separate login access for donors, hospitals, and admins.
* To reduce manual record keeping.
* To simplify blood bank management.
* To make blood availability easier to manage.

---

## 👥 User Roles

### 👤 Donor

Donors can:

* Login to their account.
* View their donor profile.
* View donation history.
* Schedule blood donations.
* View upcoming donation schedules.

### 🏥 Hospital

Hospitals can:

* Login to their hospital account.
* Request blood.
* Select required blood groups.
* Enter required blood quantity.
* View blood request status.
* Manage hospital information.

### 🛡️ Administrator

Administrators can:

* Login to the admin panel.
* Add and manage donors.
* Manage hospitals.
* Manage blood inventory.
* Manage blood requests.
* Manage donation schedules.
* Monitor system activities.

## 🔄 Blood Request Flow

```text
Hospital Login
      ↓
Select Blood Group
      ↓
Enter Required Quantity
      ↓
Submit Blood Request
      ↓
Admin Reviews Request
      ↓
Check Blood Inventory
      ↓
Approve / Reject Request
      ↓
Update Blood Inventory
      ↓
Hospital Views Request Status
```
